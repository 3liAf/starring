# Your profiles go here

Put one YAML file per person in this folder, for example `profiles/jane.yaml`.

- **No files here:** the site shows the sample profiles from `examples/`, which is demo mode.
- **One file here:** that profile becomes the home page, which is personal-site mode.
- **Several files here:** the home page lists them all.

The quickest way to start is to open `/edit`, import your GitHub profile, export `<handle>.yaml`, and drop it into this folder.
